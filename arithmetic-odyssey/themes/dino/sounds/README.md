# Dino Tour sounds

Put a recorded sound here named **`flag.mp3`** (or `flag.m4a` or `flag.wav`) and the game plays it when a player reaches a flag, instead of the roar it makes itself. Without a file, the made-up roar plays.

- **Length:** about 1 to 4 seconds. The voice waits for it (at most 4 seconds).
- **Size:** at most 600 KB (the tests check). An MP3 at 128 kbps is about 16 KB a second.
- **Loudness:** any; the game evens it out to about as loud as the voice.
- **Try it:** open the game with `?debug=1`, then **Open the voice and sound tester**: it has a button for each recording it finds.

**Credit and permission.** This repository and the game are public, so anyone can download the file. Only add a sound you are allowed to share this way: public domain (CC0) sounds are safest. Sound sites whose licenses say you may not share or redistribute the original audio file usually do not allow this. Add a line for the sound to [../CREDITS.md](../CREDITS.md), for example:
