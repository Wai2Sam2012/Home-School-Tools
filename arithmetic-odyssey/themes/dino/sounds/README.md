# Dino Tour sounds

Recorded sounds here named **`flag-1.mp3`**, **`flag-2.mp3`** and so on (or one **`flag.mp3`**; `.m4a` and `.wav` work too) play when a player reaches a flag, instead of the roar the game makes itself. With several, the game picks one at random at each flag, never the same one twice in a row. Without any, the made-up roar plays.

- **Length:** about 1 to 5 seconds. The voice waits for it to finish (at most 5 seconds).
- **Size:** at most 600 KB each (the tests check). An MP3 at 128 kbps is about 16 KB a second.
- **Loudness:** any; the game evens it out to about as loud as the voice.
- **Try it:** open the game with `?debug=1`, then **Open the voice and sound tester**: it has a button for each recording it finds.

**Credit and permission.** This repository and the game are public, so anyone can download the file. Only add a sound you are allowed to share this way: public domain (CC0) sounds are safest.
