# Dinosaur Adventure picture credits

Every picture in `pictures/` needs a line here saying where it came from, so any picture can be checked or replaced later. This repository and the published game are public, so only add pictures you are allowed to share.

A line can name one picture (`pictures/Triassic/Eoraptor/Eoraptor_156b.jpg`) or a whole folder with `/**` at the end (`pictures/Triassic/**`). A line for one picture is more exact, so add one whenever you learn a picture's artist or license.

| `pictures/**` | All | Downloaded from each dinosaur's gallery page on [dinosaurpictures.org](https://dinosaurpictures.org/) with `tools/Get-DinoPictures.ps1`. The artist is often part of the file name. | Unknown. The site collects art from many artists; check a picture's artist before reusing it elsewhere, and replace any picture an artist asks to remove. |
